# Экраны браузера Rustium для макетов

Список экранов и состояний, которые нужно нарисовать, чтобы реализовать интерфейс браузера: окно с вкладками, служебные страницы (настройки, история, cookies, загрузки), диалоги и всплывающие окна. Приоритет показывает очередность реализации.

**P0** нужно сейчас **P1** следующий этап **P2** позже

## Что уже есть и от чего отталкиваться

Платформы

macOS и Linux. На macOS окно без системного заголовка, кнопки окна («светофор») стоят в полосе вкладок слева. На Linux рамка окна системная, отступа под кнопки нет.

Панель

Высота 80px: полоса вкладок 38px + строка навигации 42px. Отступ под «светофор» 104px. Окно по умолчанию 1280×840, минимум 480×320.

Сейчас в панели

Вкладки, «+», назад, вперёд, обновить/остановить, адресная строка, кнопка DevTools, полоса загрузки.

Темы

Тёмная и светлая, по системной настройке. Нужны обе для каждого экрана.

Шрифт

Системный (`system-ui`), 13px в панели.

Цвета

#1f2024 полоса #2b2c31 панель #1b1c20 поле #f0723c акцент

Технология

Весь интерфейс браузера сделан на HTML/CSS, поэтому любые эффекты, шрифты и анимации из макета переносятся без ограничений. Выпадающие окна (меню, подсказки, загрузки) рисуются поверх страницы сайта.

## Общие требования к макетам

- Каждый экран в тёмной и светлой теме.
- Главное окно для macOS (без заголовка, со «светофором») и один вариант для Linux (с системной рамкой).
- Состояния элементов: обычное, наведение, нажатие, фокус с клавиатуры, неактивное.
- Пустые состояния для списков (нет истории, нет загрузок, нет закладок) и состояние «ничего не найдено» для поиска.
- Узкое окно (около 480px) для панели и служебных страниц.
- Сначала набор компонентов: кнопки, иконки-кнопки, поле ввода, поиск, переключатель, выпадающий список, чекбокс, строка списка, всплывающая панель, диалог, всплывающее уведомление, прогресс.

## 1. Окно и панель

Всё, что видно вокруг сайта и поверх него.

1.1

### Главное окно

**P0**

- Полоса вкладок, строка навигации, страница сайта.
- Справа от адресной строки: звезда закладки, загрузки, главное меню «⋯». DevTools уходит в меню.
- Полноэкранный режим: кнопок окна нет, отступ слева убирается.
- Неактивное окно (приглушённая панель).

1.2

### Вкладки

**P0**

- Активная, неактивная, наведение.
- Загружается (индикатор вместо favicon), без favicon, со звуком (кнопка выключить звук).
- Длинный заголовок; много вкладок (узкие вкладки, только иконка); переполнение полосы.
- Закреплённая вкладка (только иконка, всегда слева) **P2**.
- Перетаскивание вкладки **P2**.

1.3

### Адресная строка

**P0**

- Пустая с подсказкой, в фокусе, ввод текста.
- Значок слева: защищённое соединение, незащищённое (http), ошибка сертификата, служебная страница браузера.
- Отображение адреса без фокуса (например, приглушённые `https://` и путь).
- Индикатор разрешений, которые сейчас использует сайт (камера, микрофон, геолокация).

1.4

### Подсказки адресной строки

**P1**

- Выпадающий список под адресной строкой: поиск запроса, сайты из истории, закладки, открытые вкладки («перейти на вкладку»).
- Выделенная строка при навигации стрелками, совпадение в тексте выделено.

1.5

### Информация о сайте

**P1**

Открывается по клику на значок слева в адресной строке.

- Статус соединения и сертификат.
- Разрешения сайта с переключателями: камера, микрофон, геолокация, уведомления, всплывающие окна, звук.
- Cookies и данные сайта: число, объём, кнопка «Удалить данные сайта».
- Ссылка на настройки сайта.

1.6

### Запрос разрешения

**P0**

- Всплывает под адресной строкой: «example.com запрашивает доступ к камере». Кнопки «Разрешить», «Запретить», флажок «Запомнить».
- Варианты: камера, микрофон, камера и микрофон, геолокация, уведомления, буфер обмена, демонстрация экрана.

1.7

### Загрузки в панели

**P0**

- Кнопка загрузок: появляется при первой загрузке, кольцо прогресса, отметка завершения.
- Выпадающий список: имя файла, размер, скорость и оставшееся время; пауза, отмена, «Показать в Finder», повтор.
- Состояния файла: идёт, на паузе, завершён, ошибка, отменён, опасный файл (подтверждение).
- Ссылка «Все загрузки» на страницу 2.6.

1.8

### Главное меню «⋯»

**P0**

- Новая вкладка, новое окно, новое приватное окно.
- История, загрузки, закладки.
- Масштаб: «−», 100%, «+», во весь экран.
- Найти на странице, печать, инструменты разработчика.
- Настройки, о Rustium, выход.
- Горячие клавиши справа от пунктов.

1.9

### Поиск на странице

**P1**

- Поле под панелью или справа: текст, «3 из 17», вверх, вниз, закрыть.
- Состояние «не найдено».

1.10

### Закладки в панели

**P1**

- Звезда в адресной строке: пустая и заполненная.
- Всплывающее окно «Закладка добавлена»: название, папка, «Удалить», «Готово».
- Панель закладок под строкой навигации (включается в настройках): ссылки, папки, переполнение «»».

1.11

### Контекстные меню

**P1**

- Вкладка: перезагрузить, дублировать, закрепить, выключить звук, закрыть, закрыть другие, закрыть вкладки справа, открыть закрытую вкладку.
- Страница: назад, вперёд, обновить, сохранить как, печать, просмотр кода, исследовать элемент.
- Ссылка, изображение, выделенный текст, поле ввода (дополнительные пункты к меню страницы).

1.12

### Диалоги сайтов

**P1**

- Сообщение, подтверждение, ввод текста (`alert`, `confirm`, `prompt`) с адресом сайта в заголовке.
- «Покинуть сайт? Изменения могут не сохраниться» — «Покинуть», «Остаться».
- Вход на сайт (HTTP-авторизация): логин, пароль.
- Выбор сертификата клиента **P2**.

1.13

### Прочее

**P2**

- Всплывающий индикатор масштаба: «110%», «Сбросить».
- Приватное окно: отличие в оформлении панели и своя новая вкладка.
- Восстановление после сбоя: «Rustium был закрыт неожиданно. Восстановить вкладки?»
- Всплывающие уведомления браузера (например, «Ссылка скопирована»).

## 2. Служебные страницы

Открываются во вкладке, адреса вида `rustium://settings`. Лучше сделать для них общий каркас: боковое меню разделов, заголовок, поиск.

2.1

### Новая вкладка

**P1**

- Поле поиска, часто посещаемые сайты (плитки), последние закладки или недавно закрытые вкладки.
- Пустое состояние при первом запуске.
- Вариант для приватного окна **P2**.

2.2

### Настройки

**P0**

Каркас: боковое меню разделов, поиск по настройкам, на узком окне меню сворачивается.

- **Основные:** при запуске (восстановить вкладки / новая вкладка / заданные страницы), браузер по умолчанию, язык.
- **Внешний вид:** тема (системная, светлая, тёмная), размер шрифта, масштаб по умолчанию, панель закладок, кнопка «Домой».
- **Поиск:** поисковая система по умолчанию, список поисковиков, добавление своего.
- **Конфиденциальность:** cookies (разрешить все / блокировать сторонние / блокировать все), удалять данные при выходе, защита от отслеживания, только HTTPS, безопасный DNS, кнопка «Очистить данные» (2.4).
- **Разрешения сайтов:** камера, микрофон, геолокация, уведомления, всплывающие окна, JavaScript, звук, автозапуск видео. Для каждого: значение по умолчанию и списки «разрешено» / «запрещено» по сайтам.
- **Загрузки:** папка, спрашивать куда сохранять.
- **Система:** аппаратное ускорение, продолжать работу в фоне.
- **О Rustium:** версия, версия Chromium, проверка обновлений.
- Состояния: поиск по настройкам с результатами, «ничего не найдено», сохранено (уведомление).

2.3

### Cookies и данные сайтов

**P0**

- Список сайтов: favicon, домен, число cookies, объём хранилища, «Удалить».
- Поиск по сайтам, сортировка по объёму, «Удалить все» с подтверждением.
- Страница сайта: cookies (имя, значение, срок, флаги), localStorage, кэш, разрешения сайта.
- Пустое состояние.

2.4

### Очистить данные браузера

**P0**

- Диалог: период (последний час, сутки, неделя, 4 недели, всё время).
- Флажки: история, cookies и данные сайтов, кэш, история загрузок, данные форм.
- Объём для каждого пункта, кнопка «Очистить», состояние «Очищено».

2.5

### История

**P0**

- Список по дням («Сегодня», «Вчера», дата): время, favicon, заголовок, домен.
- Поиск, выбор нескольких строк, «Удалить выбранное», «Очистить данные» (2.4).
- Меню строки: открыть в новой вкладке, ещё с этого сайта, удалить.
- Недавно закрытые вкладки.
- Пустое состояние и «ничего не найдено».

2.6

### Загрузки

**P1**

- Список по дням: иконка типа файла, имя, источник, размер, статус.
- Действия: открыть, показать в Finder, повторить, удалить из списка.
- Поиск, «Очистить список», пустое состояние.

2.7

### Закладки

**P1**

- Дерево папок слева, список закладок справа.
- Добавить, переименовать, переместить (перетаскиванием), удалить; новая папка.
- Поиск, импорт из Chrome/Safari/HTML-файла, экспорт.
- Пустое состояние.

2.8

### Страницы ошибок

**P0**

Сейчас одна простая страница на всё. Нужны отдельные варианты:

- Нет подключения к интернету.
- Сайт не найден (DNS).
- Сайт не отвечает или отклонил соединение.
- Ошибка сертификата: предупреждение, «Вернуться», «Подробнее», «Перейти небезопасно».
- Вкладка упала: «Перезагрузить».
- Файл не найден (для `file://`).
- У каждой: адрес, понятная причина, что делать, код ошибки мелко.

2.9

### Первый запуск

**P2**

- Приветствие, импорт из другого браузера, выбор темы, сделать браузером по умолчанию.

2.10

### Пока не рисуем

**P2**

Пароли и автозаполнение, профили пользователей, расширения, синхронизация, группы вкладок, боковая панель. Их стоит учесть в каркасе (место в меню и в настройках), но макеты пока не нужны.

## Порядок работы

1. Набор компонентов и токены (цвета обеих тем, типографика, отступы, радиусы, иконки).
2. Экраны P0: главное окно, вкладки, адресная строка, разрешения, загрузки, меню, настройки, cookies, очистка данных, история, страницы ошибок.
3. Экраны P1, затем P2.

Для каждого экрана: размер окна 1280×840, обе темы, основное состояние и состояния из списка выше.
