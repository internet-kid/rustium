# Макеты интерфейса Rustium

Исходники экранов с холста: https://claude.ai/artifact/1pLLCjuu5eRpHaQaaT87AL
(живая версия, она может уйти вперёд от этой копии). Бриф: `../Бриф макетов Rustium.md`.

Сейчас тут все экраны P0, только тёмная тема, вкладки сверху.

## Формат

Каждый `*.dc.html` — один экран (артборд) в формате Design Component. Вся разметка
со стилями inline. Значения вида `{{accent}}` подставляет блок
`<script type="text/x-dc">` внизу файла (по умолчанию `#8b7cff`). Файл подключает
`./support.js` — это рантайм холста, его здесь нет. Поэтому в обычном браузере файл
откроется без подстановок: смотреть картинку лучше на холсте, а здесь брать
разметку, цвета и размеры. `canvas.json` — раскладка экранов на холсте.

## С чего начинать

- `Components.dc.html` — токены (цвета, шрифты, радиусы, отступы) и компоненты в
  состояниях: обычное, наведение, нажатие, фокус, неактивное.
- `States.dc.html` — состояния вкладок, адресной строки, звезды закладки и кнопки загрузок.
- `Main.dc.html` — главное окно macOS: панель 38 + 42 px, отступ под «светофор» 104 px.
- `SettingsGeneral.dc.html` — общий каркас служебных страниц `rustium://`.

## Основные токены (тёмная тема)

| Назначение | Значение |
|---|---|
| Окно / полоса вкладок | `#0e0f13` |
| Строка навигации, активная вкладка, карточки | `#1d2027` |
| Адресная строка | `#121419` |
| Страница, фон служебных страниц | `#16181e` |
| Всплывающие окна | `#22252d` |
| Текст / вторичный / приглушённый | `#eceef3` / `#c9cdd6` / `#9aa0ad` |
| Акцент / текст на акценте | `#8b7cff` / `#0e0f13` |
| Успех / предупреждение / ошибка | `#5ee6b8` / `#fbbf24` / `#ff8a80` |
| Шрифт | Geist, коды — Geist Mono |
