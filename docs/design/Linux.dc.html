Window variants

Linux with a system title bar, inactive macOS window, fullscreen.

Window chrome rules

  • Linux. The window manager draws the title bar (GTK or KDE). The tab strip loses the 104px inset and starts at 8px.
  • macOS. Hidden title bar, traffic lights at 16px, tabs start at 104px. The empty strip area drags the window.
  • Inactive. Traffic lights turn #4a4f5c. Tab and toolbar text drop one step: #eceef3 to #9aa0ad, #c9cdd6 and #9aa0ad to #6b7180. Favicons at 60%. The page is not dimmed.
  • Fullscreen. No window buttons and no corner radius. Tabs start at 8px, the toolbar stays visible.
